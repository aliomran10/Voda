# 🌴 Weather App

Weather App is an Angular web application for viewing city weather history. It allows users to explore temperature trends, humidity stats, and complete forecast data with interactive charts and tables. Users can filter by date, search for cities, and toggle between Celsius and Fahrenheit units.

---

## 🚀 Features

- 🌆 City Weather Overview – Browse current and historical weather for multiple cities.

- 📅 Date Filtering – Filter forecast data by specific dates.

- 🔍 Search Functionality – Quickly find cities using the search bar.

- 🌡️ Temperature Toggle – Switch between Celsius and Fahrenheit.

- 📊 Interactive Charts – Line chart displaying temperature trends over time.

- 📈 Statistics Cards – View min, max, and average temperatures and humidity.

- 🗂️ Forecast Table – Detailed forecast data with visual indicators for humidity and weather.

- 💻 Responsive Design – Optimized for desktop and tablet devices.

---

🛠 Tech Stack
Frontend: Angular (Standalone Components), TypeScript, HTML, CSS

Charts: Chart.js via ng2-charts

Reactive Programming: RxJS (Subjects, takeUntil)

Routing: Angular Router

---

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/aliomran10/Voda.git
cd client
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the app

```bash
npm start
```
